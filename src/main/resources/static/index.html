    Como ler / ressalvas

    ✅ Confiável: elapsedMs, throughput, WAL (LSN diff), tuplesAffected (rowcount da operação), cacheHit do SELECT (EXPLAIN BUFFERS).
    ⚠️ Indicativo: heapBlocks/cacheHit de ESCRITA — pg_statio tem lag de flush (~1s); operação rápida (INSERT/DELETE) pode reportar 0. Confiável só em volume grande.
    ⚠️ memoryDeltaKb — aproximação via Runtime+GC, pode dar negativo. Indicativo.
    ℹ️ COLD = tabela resetada antes (TRUNCATE + VACUUM FULL ANALYZE + CHECKPOINT). WARM = continua do COLD. SELECT COLD não é cache-frio real (sem restart do PG).
    ℹ️ Execução single-thread — throughput é de uma thread, não teste de concorrência.
